# bibliotemplate

> Google Apps Script for school libraries

An open-source software built with **Google Apps Script** for school library management and automation (cataloging, loans, and related library operations).

---

## 🛠️ Development Notes

* **Language & Platform:** Google Apps Script (JavaScript).
* **Code Naming Conventions:** Code entities (variables and functions) are intentionally named in Italian to align with the specific domain terminology of Italian school administration and to simplify maintenance/inspection for internal technical support staff (e.g., ATA staff, Digital Animators).
